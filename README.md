## How to Run

Open your terminal inside product-exchange-v1/ and run:
```bash
npm install
npm start
```
Visit http://localhost:3000 in your browser.
When you're ready for Step 2, let me know which layer you want to add next:
• Step 2A: Adding the Login / Register view (loginView()) and session state
• Step 2B: Adding the Sidebar layout and page switching (shell() and renderPage())
• Step 2C: Adding in-memory or JSON file data on the backend (/api/dashboard)
